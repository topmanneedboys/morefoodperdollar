# Focused ValuePilot task

## GOAL
One observable outcome.

## SCOPE
The single behavior or boundary being changed.

## FILES
Expected files to inspect or edit.

## DO NOT MODIFY
Explicit protected modules, behavior, fixtures, and public contracts.

## REQUIRED BEHAVIOR
Concrete inputs, outputs, invariants, and failure behavior.

## TESTS
Exact commands and new/updated cases required.

## DONE WHEN
Measurable acceptance criteria, including build status.

## STOP CONDITION
When to stop rather than expanding scope or guessing.
