## Advertiser-specific agreement review

The Greenworks Tools Canada Affiliate Agreement was reviewed before application.

Important advertiser-specific restrictions:

- the agreement frames the program's purpose as HTML linking between the publisher website and Greenworks Tools Canada
- affiliate tooling described in the agreement is website-oriented HTML links, banners and tracking code
- the license is limited to accessing Greenworks through HTML links and using licensed brand materials in connection with those links
- Section 8.3 expressly prohibits transmitting certain software/marketing technologies during the qualifying-link session, including `Shopping Assistance Application`, toolbar/add-on, shopping-wallet, parasiteware and deceptive popup behavior
- Section 2.1.8 separately rejects software downloads that can divert commission from other affiliates
- anti-interception/anti-cookie-overwrite rules are appropriate and align with ValuePilot's permanent no-attribution-manipulation policy, but the explicit `Shopping Assistance Application` wording creates an advertiser-specific compatibility ambiguity for ValuePilot itself

## Decision

**DO NOT APPLY TO GREENWORKS TOOLS CANADA FOR THE CURRENT 5D PASS.**

The generic Rakuten DSA flag does not resolve the advertiser-specific ambiguity. ValuePilot is itself a shopping-intelligence/shopping-assistance application, so accepting an agreement that explicitly lists `Shopping Assistance Application` among prohibited technologies would create avoidable contractual risk even if the clause is partly aimed at parasitic attribution software.

Reconsider only if Greenworks or Rakuten provides explicit written clarification that ValuePilot's non-intercepting, user-initiated comparison application is permitted under the advertiser agreement.

Do not treat Product Catalog visibility as authorization to download, cache, index, display or redistribute Greenworks product data.
