ValuePilot public website privacy notice

Effective August 22, 2026

This notice applies to this public pre-launch ValuePilot marketing website. It does not describe future application functionality that has not been released.

Data collected by this site

This static marketing site does not include ValuePilot analytics, advertising trackers, account registration, forms, payment processing, or a ValuePilot-operated application server. ValuePilot does not intentionally collect personal information through this site.

Hosting and external links

The site may be hosted by a third-party infrastructure provider, which can process ordinary technical request information such as IP addresses and request logs as part of operating and securing its service. External links, including links to GitHub or future merchant partners, are governed by those services' own privacy practices.

Affiliate and merchant links

ValuePilot is evaluating authorized commerce-data and affiliate relationships. If affiliate or merchant links are introduced, relevant disclosures and this privacy notice will be updated before those features are represented here as live functionality.

Future product privacy

ValuePilot is being developed with explicit data boundaries and provider provenance. Any future network-connected product release will receive privacy documentation appropriate to the data it actually processes.

Updates

This notice may change as ValuePilot moves from pre-launch development into public release. Material changes will be reflected on this page.
